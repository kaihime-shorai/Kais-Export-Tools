What it does

Pick a tool in the popup — each export becomes a file on your computer.

💬

Export your data

  • Full chat history as a transcript
  • Knowledge base tabs
  • Long-term memories
  • Training pairs
  • Profile & configuration
📖

Read it back beautifully

Story Reader turns transcripts into properly typeset stories. Data Viewer opens any export with full Markdown — themes, brightness control, font scaling, focus mode and search included. Every setting is remembered.

🔒

Private by design

No accounts, no servers, no analytics, no tracking. Everything runs on your machine and files save straight to your device. The extension only touches shapes.inc, and only when you click a button.

Now on your phone 📱

Everything works on Android with Vivaldi Browser — install from the same Chrome Web Store page.

How to get it on mobile: open this page in Vivaldi Browser on your Android phone, tap the install button above, and Vivaldi will add it like a desktop extension. Then open Shapes.inc, tap Vivaldi's menu, find the extension, and its menu opens as a touch-friendly page.

🆕 New to Vivaldi? It ships with extra bars switched on (tab bar, navigation bar) that clutter the screen. Hiding them takes about two minutes and makes it feel like a regular mobile browser — follow the step-by-step picture guide.

An honest note: mobile browsers give extensions far less room to work in than desktop, so the mobile experience is simpler — and it is built specifically for Vivaldi. Lemur Browser can also run it, but Lemur has a bug where the keyboard covers the chat box (they've said they won't fix it) — fine if you only pop in to export, frustrating if you actually chat. Quetta is not recommended. If anything looks off on your phone, please tell me — testing devices is limited, so reports genuinely help.
