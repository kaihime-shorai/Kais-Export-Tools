⚠️ Before you delete anything on Shapes.inc

Always open your downloaded export and check that everything you expected is actually in it. An export can only contain what the platform has loaded in your browser — if a chat wasn't fully scrolled, or a page wasn't captured, that content won't be in the file.

Verify first, delete second. If something is missing, re-capture and compare again before removing anything — chats, memories, knowledge tabs, or a shape itself.

2Chat exporter

  1. Open the chat you want to save on talk.shapes.inc.
  2. Click the extension icon, then Start Chat Exporter. The page will refresh itself — that's normal, don't worry. Refreshing lets the exporter hook in from the very start so it can capture everything, including the most recent messages. A capture panel then appears in the bottom-right corner.
  3. Scroll up through the chat to load older messages. Each batch that loads is captured automatically — the counter in the panel shows how many messages you have.
  4. When you've reached as far back as you want, click Download Chat. You get a plain .txt transcript, oldest first.
  5. Click Turn Off (or the ✖) when you're done — capture switches off completely, no reload needed.

3Data exporters

Each data exporter works the same way: open the relevant page for your shape on Shapes.inc, click the matching button in the extension popup, and a panel appears on the page.

For exporters with multiple pages or tabs, capture one section, then move to the next and capture again — the panel keeps a running count. When everything is captured, use the panel's download button to save the complete .json file.

Expand everything before you capture. An exporter can only grab what the page has actually loaded and rendered — if a section is collapsed (folded-away lists, closed ▾ sections, "show more" links), open it first or that content won't be in your export.

Files are named after your shape (for example kestrel_Knowledge_Complete_Export.json) so exports from different shapes never get mixed up.

4Reader & viewer

Story Reader turns a chat .txt export into a story: per-speaker colors, timestamps, optional engine names, and command cleanup (!wack, !sleep, !reset can be kept, replaced with story text, or stripped).

Data Viewer opens any .json export — knowledge base, memories, training pairs, or profile — and detects the format automatically. Markdown formatting like **bold**, *italic*, lists, headings, and links renders properly.

Both pages include search (/ to focus, Enter to jump between matches), font-size controls, focus mode, four page themes, four reader themes, custom text colors with a low-contrast warning, and a brightness slider. Every setting is remembered between visits and shared between the two pages.

5Privacy

Everything stays on your computer. Captured chats and exports live only in the page's memory until you download them. Settings are stored in your browser's local storage. There is no account, no server, no analytics, and nothing you export is ever sent anywhere.

The extension only runs on shapes.inc and talk.shapes.inc, and only when you click a button. The reader, viewer, and this help page work fully offline once loaded.

6FAQ

Where do my downloads go?

Wherever your browser normally saves downloads (usually your Downloads folder). The extension never moves or uploads them anywhere else.

Why didn't my export grab everything on the page?

Check for collapsed sections first — anything folded away behind a ▾ arrow or "show more" link isn't loaded into the page, so the exporter can't see it. Expand every section, then capture again. Also make sure you captured every page or tab of the section (the panel's running count should match what you expect) before downloading.

The chat capture counter says 0 — what's wrong?

Usually, nothing yet — the counter only climbs as message history loads. After the automatic refresh, whatever is currently visible in the chat is captured straight away, and scrolling up loads (and captures) older batches.

If it's still 0 after the refresh and some scrolling, then either the chat room is genuinely empty, or something on the platform's side has changed and the exporter can't read it — please report that (see below) so it can be fixed.

Do I need to turn the chat exporter off?

It's good practice. Turn Off unhooks the capture completely. If you forget, it stays off for other sites — it only ever runs on Shapes.inc — but it will reactivate the next time you reload a Shapes.inc chat page.

Does this work in both Chrome and Edge?

Yes — it's a Manifest V3 extension, tested in both. Any Chromium-based browser that supports MV3 extensions should work.

My reader/viewer theme reset — why?

Settings are kept in local storage. Clearing your browser's site data for extension pages resets them. Themes, colors, font size, and brightness otherwise persist indefinitely.

Can I delete my chat / memories / shape after exporting?

Only after you've opened the downloaded file and personally confirmed everything you care about is in it. Exports contain only what the platform loaded in your browser while capturing — incomplete scrolling or a skipped page means missing content. The extension can't recover anything deleted on Shapes.inc, so verify first, delete second.

The viewer didn't recognize my file.

Make sure it's a .json file produced by this extension's exporters. Files edited by hand can break the expected structure — if in doubt, re-export.

Does it work on mobile / Android?

Yes — on Vivaldi Browser for Android. Switch this page to the 📱 Mobile view (buttons at the top) for the full mobile guide, and see the short picture guide to making Vivaldi feel like a regular mobile browser (hiding its tab and navigation bars).

6FAQ

Which mobile browser do I need?

Vivaldi Browser on Android — it's what mobile support is built and tested on. Lemur Browser can also run it, but Lemur has a keyboard bug that covers the chat input box (and they've said they won't fix it), so it's only practical if you're popping in purely to export. Quetta can load the extension but displays and behaves weirdly, so we don't recommend it. Mobile Chrome and Safari can't run extensions like this at all.

Why do the colours look different on mobile?

Every part of the extension follows your browser's light/dark mode until you touch a ☀️/🌙 toggle — then it remembers your choice. There are two independent toggles: one in the extension menu (which also sets the export panels on the page), and one at the top of the reader/viewer/help pages. So you can read in dark while exporting in light, or vice versa. (On Lemur, the menu is always dark when Lemur is in dark mode — the browser forces it.)

I tapped an export option and nothing happened?

It probably did — the menu opens as its own page on mobile, so the result is on your Shapes.inc tab. Switch back to it: the export panel will be waiting at the bottom of the page.

How do I open the extension menu on mobile?

In Vivaldi, open the browser's own menu and look under Extensions — tap Kai's Export Tools and the menu opens as its own page. Hiding Vivaldi's navigation bar and tab bar gives everything more room — see the picture guide.

The chat capture counter says 0 — what's wrong?

First make sure you've switched back to the chat tab and are looking at the chat page itself — the panel with the counter sits at the bottom of the page. The counter only climbs as message history loads: after the automatic refresh, whatever is currently visible is captured straight away, and scrolling up loads (and captures) older batches.

If it's still 0 after the refresh and some scrolling, then either the chat room is genuinely empty, or something on the platform's side has changed and the exporter can't read it — please report that (see below) so it can be fixed.

Where did my export download to?

Into Vivaldi's downloads — check Vivaldi's download manager (in its menu) or your phone's file manager; the exact location varies by phone. From there you can share or move the file, then open it in the Story Reader or Data Viewer.

Why didn't my export grab everything on the page?

Check for collapsed sections first — anything folded away behind a ▾ arrow or "show more" link isn't loaded into the page, so the exporter can't see it. Tap to expand every section, then capture again. Also make sure you captured every page or tab of the section (the panel's running count should match what you expect) before downloading.
